## Serviço `Postgres`

Não copie as variáveis da aplicação para o banco. Mantenha as variáveis geradas pelo Railway, como:

```env
DATABASE_URL=postgresql://${{PGUSER}}:${{POSTGRES_PASSWORD}}@${{RAILWAY_PRIVATE_DOMAIN}}:5432/${{PGDATABASE}}
PGDATA=/var/lib/postgresql/data/pgdata
PGDATABASE=${{POSTGRES_DB}}
PGHOST=${{RAILWAY_PRIVATE_DOMAIN}}
PGPASSWORD=${{POSTGRES_PASSWORD}}
PGPORT=5432
PGUSER=${{POSTGRES_USER}}
POSTGRES_DB=railway
POSTGRES_PASSWORD=<GERENCIADA_PELO_RAILWAY>
POSTGRES_USER=postgres
```

A aplicação referencia o banco apenas por `DATABASE_URL=${{Postgres.DATABASE_URL}}`.
